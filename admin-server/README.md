# Админка меню ROCK HATA на Raspberry Pi

Маленький сервер на Raspberry Pi Zero 2 W. Через него директор правит меню с телефона или ноутбука, из любого интернета, по постоянной ссылке. Домен покупать не нужно.

Как это работает:
- Админка хранит меню в своей базе. После каждой правки она сама обновляет `menu-data.js` в этом репозитории, и через 1–2 минуты изменения видны на https://rockhatabar.github.io/.
- Сам сайт по-прежнему раздаёт GitHub Pages. Если плата выключена, сайт с меню продолжает работать, недоступна только админка.
- Постоянную ссылку вида `https://rockhata.tailXXXX.ts.net` бесплатно даёт Tailscale Funnel.

> **Важно:** после запуска админки меню правится **только через неё**. Если поменять `menu-data.js` вручную, эти правки затрутся при следующем сохранении в админке. Фотографии по-прежнему добавляются в папку `img/` репозитория отдельно, а в админке у позиции указывается путь к фото (например, `img/negroni.jpg`).

## Что понадобится

- Raspberry Pi Zero 2 W и карта microSD от 8 ГБ (лучше серии High Endurance).
- Блок питания 5 В / 2.5 А с разъёмом **micro-USB**.
- Wi-Fi бара в диапазоне **2.4 ГГц** (5 ГГц плата не видит).
- Ноутбук с Windows для первой настройки.

## 1. Новый GitHub-токен

Старый токен засветился в переписке, поэтому сначала отзовите его, а потом создайте новый.

1. github.com → аватар → **Settings** → внизу слева **Developer settings** → **Personal access tokens** → **Fine-grained tokens**.
2. Старый токен: откройте его → **Delete**.
3. **Generate new token**:
   - Token name: `rockhata-pi`
   - Expiration: максимальный срок (до года; когда истечёт, замените командой `--token`, см. ниже)
   - Repository access: **Only select repositories** → `RockHataBar/RockHataBar.github.io`
   - Permissions → Repository permissions → **Contents: Read and write**
4. **Generate token** и сразу скопируйте его (`github_pat_…`). Никуда не отправляйте: он понадобится только на шаге 4.

## 2. Запись карты памяти

1. Скачайте и запустите **Raspberry Pi Imager** (raspberrypi.com/software).
2. Устройство: **Raspberry Pi Zero 2 W**. ОС: **Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit)**. Накопитель: ваша карта.
3. Когда Imager предложит изменить настройки, нажмите **Edit settings**:
   - hostname: `rockhata`
   - имя пользователя и пароль (запомните: они нужны для входа на плату)
   - Wi-Fi: название и пароль сети бара, страна **UA**
   - вкладка **Services**: включить **SSH** (вход по паролю)
4. Запишите карту, вставьте её в плату и подайте питание. Подождите 3–5 минут: первый запуск долгий.

## 3. Вход на плату с ноутбука

Ноутбук должен быть в той же Wi-Fi сети. Откройте **PowerShell** и введите (вместо `pi` — имя пользователя из шага 2):

```
ssh pi@rockhata.local
```

На вопрос `Are you sure you want to continue connecting` ответьте `yes`, затем введите пароль от платы (при вводе он не отображается).

## 4. Установка

Скопируйте и выполните одну строку:

```
sudo apt update && sudo apt install -y git && git clone https://github.com/RockHataBar/RockHataBar.github.io.git && sudo bash RockHataBar.github.io/admin-server/pi/install.sh
```

Скрипт всё сделает сам (10–15 минут) и по ходу спросит:
1. **GitHub-токен** из шага 1. Вставьте его правой кнопкой мыши и нажмите Enter. Символы при вставке не отображаются, так и должно быть.
2. **Логин и пароль для админки.** Их будет вводить жена.
3. **Вход в Tailscale.** Скрипт покажет ссылку `https://login.tailscale.com/…`. Откройте её на ноутбуке и войдите (например, через Google).
4. **Включение Funnel.** Если появится ещё одна ссылка, откройте её и нажмите **Enable**.

В конце скрипт крупно покажет адрес админки.

## 5. Отключить срок действия ключа (один раз)

https://login.tailscale.com/admin/machines → у машины **rockhata** нажмите **…** → **Disable key expiry**.

Без этого через 180 дней ссылка перестанет работать, пока плату не переподключат к Tailscale.

## 6. Ссылка для жены

Отправьте ей адрес из шага 4. Он открывается с телефона и с ноутбука, по Wi-Fi и по мобильному интернету.

На телефоне его удобно добавить на экран «Домой»: в Safari «Поделиться» → «На экран Домой», в Chrome ⋮ → «Добавить на главный экран».

Как пользоваться: исправить поле и нажать куда-нибудь вне его. Сохранение происходит сразу, через 1–2 минуты правка видна на сайте. Цену можно вводить просто числом: `150` сам превратится в `150 ₴`.

## Обслуживание

Все команды выполняются на плате (`ssh pi@rockhata.local`):

| Что нужно | Команда |
|---|---|
| Сменить логин или пароль | `sudo bash RockHataBar.github.io/admin-server/pi/install.sh --password` |
| Заменить GitHub-токен (истёк) | `sudo bash RockHataBar.github.io/admin-server/pi/install.sh --token` |
| Обновить программу | `cd RockHataBar.github.io && git pull && sudo bash admin-server/pi/install.sh` |
| Посмотреть журнал ошибок | `sudo journalctl -u rockhata-admin -n 50` |
| Узнать адрес админки | `tailscale funnel status` |

- **Плату выключили или перезагрузили.** Ничего делать не нужно: админка и ссылка поднимаются сами через 1–2 минуты после включения.
- **Админка пишет «не вдалося опублікувати».** Правка сохранена в базе, но не ушла на сайт (обычно пропал интернет). Она уйдёт вместе со следующим сохранением. Если сообщение повторяется, проверьте, не истёк ли токен.
- **Карта памяти умерла.** Запишите новую (шаги 2–4). Меню подтянется с сайта автоматически, заново придётся задать только логин и пароль.

## Для разработчика

- Node.js ≥ 22.13 (встроенный `node:sqlite`), Express 5. Нативных модулей нет.
- `src/index.js` отдаёт панель (`public/index.html`) и API `/api/auth`, `/api/menu` на `127.0.0.1:3000`. Снаружи доступ только через Tailscale Funnel.
- `src/publish.js` генерирует `menu-data.js` из базы, меняет `?v=` в `index.html` и пушит в `main`. Публикации идут по одной, одновременные сохранения объединяются. Токен передаётся через переменные окружения git и на диск в `.git/config` не пишется.
- Конфигурация: `/etc/rockhata/admin.env`, данные и рабочий клон сайта: `/var/lib/rockhata/`, служба: `rockhata-admin` (systemd).
- Локальный запуск для проверки:
  ```
  cd admin-server && npm ci
  export DB_PATH=/tmp/rh.db REPO_DIR=/tmp/rh-repo JWT_SECRET=dev GITHUB_REPO_URL=file:///path/to/bare-copy.git
  node src/migrate.js && node src/import-existing.js ../menu-data.js
  ADMIN_PASSWORD=secret123 node src/set-password.js admin
  node src/index.js   # http://127.0.0.1:3000
  ```
  Для `GITHUB_REPO_URL` используйте локальную bare-копию, иначе правки уйдут на настоящий сайт.
